# KISHelper

## 简介
通过查询凭证号，来源单号，以及核销日期等条件，选择对应的业务核销信息，生成金蝶引入凭证。

## 引入文件格式
### 主数据引入格式
1.引入数据所在的工作表必须要在第1个(SheetIndex)，或者引入数据所在工作表名称为“核销数据”。
2.引入工作表的字段标题必须在第一行，字段对应的关系是：
[AccNumber]			凭证号
[BillWayNumber]		来源单号（可以是运单号，配载批次号，送货批次号等等）
[AccType]			核销类型
[DetailID_FFlex6]	核算客户
[DetailID_FFlex5]	核算部门
[DetailID_FFlex4]	核算客户
[AMOUNT]			核销金额
[TRANSDATE]			核销时间
### 其他数据引入格式
#### 核算规则设置
1.引入数据工作表必须在第一个。
2.引入工作表字段标题必须在第一行，字段标题为：
[名称],[科目],[余额方向],[核算维度],[默认部门]
3.名称必须要与主数据里[AccType]核销类型对应，如果核销类型里有，而核算规则表名称里没有这个类型，即没有对这个类型设置核算规则，无法生成正确的引入凭证。
4.余额方向必须要结合业务场景来填写，非金蝶内的余额方向，这里要根据增加或是减少来填写余额方向，例如：中转费核销，这里是支付中转费，那么应该是负债科目减少，余额方向应该填写借方（如果是计提中转费，才是负债科目增加，余额方向填贷方）
5.核算维度根据金蝶必选维度填写，多个维度用“/”隔开，目前支持的核算维度有“部门,客户,供应商,费用类型”
6.默认部门是方便某些特定业务手工增加分录的时候，简化部门选择的，比如开票服务费默认税务部，省去了选择部门的操作。默认部门是根据核算维度部门项目设置引出的列表，如果核算维度没有设置部门，这里的默认部门也取不到数。
#### 核算维度设置
1.引入数据工作表必须在第一个。
2.引入工作表字段标题必须在第一行，字段标题为：
[维度类型],[维度名称],[维度编码],[核算科目],[银行维度]
