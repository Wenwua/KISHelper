# KISHelper

## 简介
这是一个从事财务工作人员写的金蝶凭证引入助手，
通过查询凭证号，来源单号，以及核销日期等条件，选择对应的业务核销信息，生成金蝶引入凭证。

## 引入文件格式
### 主数据引入格式
1.引入数据所在的工作表必须要在第1个(从1开始计数)，或者引入数据所在工作表名称为“核销数据”。
2.引入工作表的字段标题必须在第一行，字段应当与程序显示的字段标题一致。
### 其他数据引入格式
其他数据，即配置文件，存储在程序运行目录data.json里，如果需要大批量的查找替换直接修改此文件（没有或删除这个文件，需要重新配置基础信息）。
#### 核算规则设置
1.引入数据工作表必须在第一个。
2.引入工作表字段标题必须在第一行，字段应当与程序显示的字段标题一致。
3.所属组织与账簿名称对应，设置了账簿名称，就更将核算规则设置到账簿，方便不同账簿，同种业务类型，不同的核算规则。
4.名称必须要与主数据里核销类型对应，如果核销类型里有，而核算规则表名称里没有这个类型，即没有对这个类型设置核算规则，无法生成正确的引入凭证。
5.余额方向必须要结合业务场景来填写，非金蝶内的余额方向，这里要根据增加或是减少来填写余额方向，例如：中转费核销，这里是支付中转费，那么应该是负债科目减少，余额方向应该填写借方（如果是计提中转费，才是负债科目增加，余额方向填贷方）
6.核算维度根据金蝶必选维度填写，多个维度用“/”隔开，目前支持的核算维度有“部门,客户,供应商,费用类型，银行账号”
7.默认部门是方便某些特定业务手工增加分录的时候，简化部门选择的，比如开票服务费默认税务部，省去了选择部门的操作。默认部门是根据核算维度部门项目设置引出的列表，如果核算维度没有设置部门，这里的默认部门也取不到数。
#### 核算维度设置
1.引入数据工作表必须在第一个。
2.引入工作表字段标题必须在第一行，字段应当与程序显示的字段标题一致。
3.所属组织设置规则同核算规则所属组织。
4.维度类型这里设置单个类型，根据核算规则获取对应的维度类型。
5.维度名称取业务系统里的名称，如部门取业务系统部门，客户取发货单位，这里主要是用业务系统信息与金蝶维度编码做映射。
6.维度编码为需要核算到金蝶的维度编码。
7.核算规则只有维度类型为银行账号的，才需要设置，如根据银行账号选择核算规则为库存现金或是公司账户，或是其他货币资金，或是油卡钱包等。
8.所属部门默认不填，只有平台公司，需要对银行账户做主体区分的，才需要给银行设置所属部门，注意：一旦给银行账号设置了所属部门，银行账号就会增加部门核算维度，且会根据对方所属部门判断是否一致挂内部往来。
9.往来主体默认不填，只有平台公司，需要对部门设置往来主体（金蝶里是客户维度），才在这里填写往来主体的名称,比如平台公司和线路要设置独立往来，先增加部门平台，线路，平台的维度编码为往来的客户编码，然后设置A部门的往来主体为平台或是线路，B银行账号的所属部门为平台或是线路，当部门的主体与银行的所属部门不一致，会自动挂内部往来。
## 合并数据
1.合并数据根据多个合并方案，将目标文件夹下的所有Excel文件合并成主数据的引入样式。
2.程序会根据目标文件夹下所有Excel文件的名称，去匹配合并方案再进行合并，若其中的文件未匹配到合并方案，将会跳过该文件。
3.合并方案根据文件名进行匹配，匹配条件一般是包含或等于，如果同一个文件满足多个合并方案，只会按照第一个方案进行合并。
4.工作表序列为数据所在的工作表序数，一般设置为1.
5.类型这里填这个表格里的数据最终属于什么核销类型的数据，这里设置的类型最终将要与核算规则里设置的核销类型对应。
6.字段序列要遵循json格式，即每个字段在对应表格所在的序列，这里只需要设置需要的字段，不需要的字段可以不设置。
7.因为核销报表内有很多脏数据，所以最终会将数据进行清洗，没有金额（或金额为0），没有核销时间的数据都会被过滤，如果需要引入非核销报表的数据，要么不设置这两个字段，如果设置必须确保金额不为0，或是核销时间有值。
8.合并方案存储在程序运行目录SheetStructure.json里，没有或删除这个文件，需要重新配置合并规则。
## 转换流程
1.配置好基础信息，并引入核销数据后，根据原始凭证上的核销报表，输入对应的凭证号，来源单号，或是核销日期，查询对应的核销信息，比对查询到的金额与单据上的金额是否一致。要查询的凭证号，来源单号，或是核销日期支持模糊查询，如凭证号O2026011252356854，可以直接输入其中几位连续数字查询，如“56854”，“112523”等等。
2.核销报表内数据信息匹配后，可以通过双击单条数据，将数据移动到右边数据栏，或是直接按“→”键，将查询到的所有信息移动到右栏。
3.如果单据上有不在核销报表内反映的交易，如对账差异，或是服务费等，提前在维护好了此类核算规则后，在右边的数据栏手动添加。
4.右栏合计金额与单据上完全一致后，点击保存，然后就可以查询下一个单据了。
5.单据都转换完毕后，点击导出，文件默认导出到导入数据所在的文件夹，并创建一个带时间戳，名为引入数据的文件。
## 注意事项
1.如果查询到的数据没有设置核算规则，会导致无法生成正确凭证。
2.如果核算规则有部门，客户，供应商，但是查询到的信息没有这些信息，会自动按照归集部门，零星客户，零星供应商来进行匹配，前提是需要在核算维度里设置这些信息。
3.没有给银行账号指派核算规则，会直接提示无法继续转换。
4.平台公司挂往来，需要在核算规则里设置核销类型“内部往来”，并指派科目为一般往来科目或是其他往来科目。
5.在数据没有导出前，数据都会暂存在内存中，如果点击了导出会清理掉所有暂存数据，点保存没点导出，后关掉程序会丢失所有暂存数据。
